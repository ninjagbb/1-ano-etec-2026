# ☕ Programming & Algorithms (Java)

This folder centralizes code examples, practical exercises, and class activities developed during the Programming and Algorithms coursework at ETEC, utilizing Java for software development, logic building, and computational problem-solving.

## 📂 Code Files & Descriptions

- **[Exemplo.java](./Exemplo.java)**: Introduction to primitive types and basic input/output[cite: 14].
  - *What it does*: Declares variables, handles primitive types (`double`, `int`, `boolean`), applies arithmetic/logical operators, and processes basic personal data input[cite: 14].
  - *Tools & Elements Used*: Primitive types, string concatenation, console output (`System.out.println`), and `JOptionPane` dialogs[cite: 14].

- **[Exemplo2(1).java](./Exemplo2(1).java)**: Practical exercises on data type casting and conditional validation[cite: 19].
  - *What it does*: Converts text strings into numeric values and applies simple conditional statements to validate age requirements[cite: 19].
  - *Tools & Elements Used*: Data parsing (`Double.parseDouble`, `Integer.parseInt`), `JOptionPane` dialog windows, and `if-else` decision flows[cite: 19].

- **[Exemplo3.java](./Exemplo3.java)**: Comprehensive collection of sequential logic and mathematical exercises[cite: 20].
  - *What it does*: Solves seven distinct problems including triangle area calculations, average stock levels, currency conversion (USD to BRL), unit conversion, profit margin pricing, employee commissions with INSS deductions, and hourly wage calculations[cite: 20].
  - *Tools & Elements Used*: Arithmetic formulas, `double` precision typing, input collection, and result output via `JOptionPane` and console[cite: 20].

- **[ativ2.java](./ativ2.java)**: Practical assignment featuring a comprehensive collection of sequential logic and mathematical exercises[cite: 8].
  - *What it does*: Solves multiple distinct computational problems, including vehicle fuel consumption per kilometer, time unit conversions (seconds to minutes and hours), temperature scale conversions (Celsius, Fahrenheit, Kelvin), Body Mass Index (BMI) calculations, and financial investment modeling with both simple and compound interest[cite: 8].
  - *Tools & Elements Used*: `JOptionPane` dialog windows (`showInputDialog` and `showMessageDialog`) for input/output, data type casting (`Double.parseDouble`), arithmetic formulas, and mathematical exponentiation libraries (`Math.pow`)[cite: 8].

- **[ativford.java](./ativford.java)**: Practical exercises exploring loop structures and automated counting flows[cite: 12].
  - *What it does*: Generates multiplication tables based on user input, executes countdowns, handles step-based decrements, and formats patterned console outputs[cite: 12].
  - *Tools & Elements Used*: `for` iteration loops, conditional variables, and formatted console printing (`System.out.println`)[cite: 12].

- **[exemploAula09.java](./exemploAula09.java)**: Advanced conditional structures and logical operators script[cite: 21].
  - *What it does*: Categorizes age groups, processes case-insensitive text responses, computes progressive salary increases based on salary tiers, and evaluates logical criteria for driver job vacancies[cite: 21].
  - *Tools & Elements Used*: Chained `if-else` statements, logical operators (`&&`, `||`, `!`), string comparison methods (`equalsIgnoreCase`), and confirm dialogs[cite: 21].

- **[atividadenova.java](./atividadenova.java)**: Comprehensive conditional calculation and business logic script[cite: 13].
  - *What it does*: Computes hotel accommodation totals, applies distinct service tax rules based on the length of stay, checks for customer discount vouchers, and generates a formatted bill summary[cite: 13].
  - *Tools & Elements Used*: `if-else` conditional statements, `JOptionPane` confirm dialogs (`YES_NO_OPTION`), and text formatting (`String.format`)[cite: 13].

- **[Arrayt.java](./Arrayt.java)**: Academic records management script utilizing one-dimensional arrays[cite: 16].
  - *What it does*: Manages student grades, automatically generates random test scores, calculates individual averages, determines student status (Approved, Recovery, or Failed), and tracks overall statistics[cite: 16].
  - *Tools & Elements Used*: One-dimensional arrays (`double[]`, `String[]`), `Math.random()` for test score generation, nested conditional evaluations, and tabular console output formatting[cite: 16].

- **[array(1).java](./array(1).java)**: Advanced human resources and payroll management system[cite: 15].
  - *What it does*: Manages a roster of employees, computes random gross salaries and registration numbers, calculates progressive tax deductions, determines net salaries, computes departmental averages, and provides an interactive search menu[cite: 15].
  - *Tools & Elements Used*: Parallel arrays, `Math.random()`, `Math.floor()` for rounding, `do-while` loops, `switch-case` control structures, and interactive `JOptionPane` search prompts by registration number[cite: 15].

- **[matrz.java](./matrz.java)**: Multidimensional arrays practical assignment[cite: 5, 22].
  - *What it does*: Implements creation of multidimensional arrays, automated random filling, mathematical operations between matrices (addition, product, difference), row sum calculations, and an interactive number search system[cite: 5, 22].
  - *Tools & Elements Used*: 2D arrays (`int[][]`), nested `for` loops, `Math.random()`, and interactive query dialogs[cite: 5, 22].

- **[AtivPOO.java](./AtivPOO.java)**: Freight and merchandise management system structured using Object-Oriented Programming[cite: 11, 25].
  - *What it does*: Manages merchandise data, computes traveled distances, calculates product values, applies conditional distance-based freight taxes, and generates summary reports[cite: 11, 25].
  - *Tools & Elements Used*: Object-Oriented Programming concepts (classes, attributes, modular methods), interactive main menus with `do-while` and `switch-case` structures, and `JOptionPane` dialogs[cite: 11, 25].

- **[AtivNaval.java](./AtivNaval.java)**: Interactive Battleship game implementation[cite: 17].
  - *What it does*: Initializes a 2D board with water, randomly places ships using random generation, and prompts the user for attack coordinates to validate hits or misses[cite: 17].
  - *Tools & Elements Used*: 2D string arrays (`String[][]`), nested loops, `Math.random()`, `do-while` loops, and conditional validations with `JOptionPane`[cite: 17].

- **[ContaCorrente.java](./ContaCorrente.java)**: Complete banking management system built with Object-Oriented Programming[cite: 18].
  - *What it does*: Manages account balances, processes deposits and withdrawals, verifies security passwords, and simulates loan financing based on customer credit scores[cite: 18].
  - *Tools & Elements Used*: Object-Oriented Programming (classes, attributes, methods with/without return and parameters), `do-while` loops, `switch-case` menus, and `JOptionPane`[cite: 18].

- **[Yuri Oliveira.java](./Yuri Oliveira.java)**: Automated electronic voting simulation system[cite: 23].
  - *What it does*: Registers voters and candidate names, simulates random voting, computes individual percentages, determines the winning candidate using mathematical maximum functions, and outputs structured reports with repetition options[cite: 23].
  - *Tools & Elements Used*: `do-while` loops, dynamic counters, `Math.random()`, `Math.max()`, and formatted dialog reports[cite: 23].
