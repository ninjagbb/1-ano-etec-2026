# ☕ Programming & Algorithms (Java)

This folder centralizes code examples, practical exercises, and class activities developed during the Programming and Algorithms coursework at ETEC, utilizing Java for software development, logic building, and computational problem-solving.

## 📂 Code Files & Descriptions

- **[ativ2.java](./ativ2.java)**: Practical assignment featuring a comprehensive collection of sequential logic and mathematical exercises.
  - *What it does*: Solves multiple distinct computational problems, including vehicle fuel consumption per kilometer, time unit conversions (seconds to minutes and hours), temperature scale conversions (Celsius, Fahrenheit, Kelvin), Body Mass Index (BMI) calculations, and financial investment modeling with both simple and compound interest.
  - *Tools & Elements Used*: `JOptionPane` dialog windows (`showInputDialog` and `showMessageDialog`) for input/output, data type casting (`Double.parseDouble`), arithmetic formulas, and mathematical exponentiation libraries (`Math.pow`).

- **[ativford.java](./ativford.java)**: Practical exercises exploring loop structures and automated counting flows.
  - *What it does*: Generates multiplication tables based on user input, executes countdowns, handles step-based decrements, and formats patterned console outputs.
  - *Tools & Elements Used*: `for` iteration loops, conditional variables, and formatted console printing (`System.out.println`).

- **[atividadenova.java](./atividadenova.java)**: Comprehensive conditional calculation and business logic script.
  - *What it does*: Computes hotel accommodation totals, applies distinct service tax rules based on the length of stay, checks for customer discount vouchers, and generates a formatted bill summary.
  - *Tools & Elements Used*: `if-else` conditional statements, `JOptionPane` confirm dialogs (`YES_NO_OPTION`), and text formatting (`String.format`).

- **[Arrayt.java](./Arrayt.java)**: Academic records management script utilizing one-dimensional arrays.
  - *What it does*: Manages student grades, automatically generates random test scores, calculates individual averages, determines student status (Approved, Recovery, or Failed), and tracks overall statistics.
  - *Tools & Elements Used*: One-dimensional arrays (`double[]`, `String[]`), `Math.random()` for test score generation, nested conditional evaluations, and tabular console output formatting.

- **[array(1).java](./array(1).java)**: Advanced human resources and payroll management system.
  - *What it does*: Manages a roster of employees, computes random gross salaries and registration numbers, calculates progressive tax deductions, determines net salaries, computes departmental averages, and provides an interactive search menu.
  - *Tools & Elements Used*: Parallel arrays, `Math.random()`, `Math.floor()` for rounding, `do-while` loops, `switch-case` control structures, and interactive `JOptionPane` search prompts by registration number.
