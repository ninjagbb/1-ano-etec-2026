# 🗄️ Database Management (MySQL)

This folder centralizes all database models, SQL scripts, and schema structures developed during the Database coursework at ETEC. During the course, multiple database projects were developed to apply practical modeling and SQL concepts.

## 📁 Code Files & Projects
- **[Cota Price](./cotaprice.sql)**: Collaborative database and web interface project developed for market price tracking.
  * *What it does*: Defines database tables, relationships, and data structures (`tblCidade`, `tblItem_Nota`, `tblNotaFiscal`, `tblProduto`, `tblUf`, `tblsupermercados`), along with a complementary HTML web interface. The project models product, invoice, and store data, with potential for future feature enhancements, though active investment or commercial development is not planned. In the 2nd year, the team will learn how to integrate dynamic database connections directly with the HTML frontend.
  * *Data Authenticity*: All registered products, prices, and invoice records were sourced from real-world shopping receipts collected by team members.
  * *Team Members*: Valentina Moreira, João Pedro Ferraz, Lyncon Lopes, and Yuri Paes (Group formed via random selection).
  * *Tools & Elements Used*: MySQL DDL/DML scripts, table structure definitions, primary/foreign key relationships, real receipt data integration, and HTML5 frontend structure.
