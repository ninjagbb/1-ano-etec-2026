# 🌿 Medicinal Plants Menu (Livro de Ervas)

Web page developed as part of the Web Programming I coursework at ETEC, featuring a complete digital catalog and guide of medicinal plants, popular names, descriptions, and therapeutic uses.

## 🚀 Technologies Used
* **HTML5**: Semantic structure, anchor links for internal navigation, and formatted text elements.

## ✨ Features
* **Quick Navigation Menu**: Direct anchor links allowing users to jump instantly to any plant profile (from Abóbora to Erva-Doce) or return to the top.
* **Detailed Botanical Records**: Includes popular names, scientific nomenclature, family classification, parts used, description, cultivation guidelines, medical indications, and preparation methods for each plant.
