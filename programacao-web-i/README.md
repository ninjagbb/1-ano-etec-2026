# 🌐 Web Programming I

This folder centralizes all examples, code, and practical activities developed during the Web Programming I coursework at ETEC.

## 📂 Activities and Projects

- **[Medicinal Plants - Angico-Manso](./plantas-medicinais)**: Practical activity assigned by the professor where each student developed a web page dedicated to a specific plant from the herbal book. This project features the documentation, descriptions, cultivation, and therapeutic indications focused on the **Angico-Manso** species, built using **HTML5** (semantic structuring, internal navigation anchor links, and text formatting).
- **[Mother's Day - Passion Fruit Mousse Recipe](./mousse-de-maracuja)**: Special thematic project showcasing a favorite family recipe complete with ingredients tables, step-by-step instructions, and a photo tribute section dedicated to mothers, built using **HTML5** (semantic structuring, tables, image embedding, and inline styling).
