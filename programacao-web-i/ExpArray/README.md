🍎 Fruit Array Form (ExpArray)
Web page developed as a practical exercise in Web Programming I at ETEC, featuring an interactive form designed to capture user input and manipulate data arrays dynamically.

🚀 Technologies Used
- HTML5: Semantic structure for building the user input form, required input fields, action buttons, and designated display containers.
- JavaScript (External Script): Modular logic implementation (`_js/script.js`) handling form submission events, DOM manipulation, array population, and alphabetical data sorting.

✨ Features
- Interactive Array Manipulation: Captures 5 fruit names entered by the user, stores them in a JavaScript array, and automatically sorts the entire list alphabetically using the `.sort()` method.
- Dynamic DOM Rendering: Creates and injects HTML elements (`<h3>`, `<ul>`, and `<li>`) on the fly to display the sorted list directly on the page without reloading.
- Active UI Cleanup: Includes a functional "Limpar lista" button with an event listener that instantly clears the generated results and HTML content from the screen.
