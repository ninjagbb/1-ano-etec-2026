# 🍋 Mother's Day: Passion Fruit Mousse

Web page developed as part of a Mother's Day assignment in Web Programming I at ETEC, combining a favorite family dessert recipe with a photo tribute gallery dedicated to mothers.

## 🚀 Technologies Used
- **HTML5 & Inline CSS**: Semantic structuring, centered tables for displaying ingredients and utensils, alongside custom visual styling via attributes (background colors, fonts, bordered cards, and box shadows).
- **Asset Organization (`_img/`)**: Dedicated and well-structured folder containing all project media, neatly separating final dish photos, ingredients, utensil icons, preparation steps, and the special memory photo gallery.

## ✨ Features
- **Complete Recipe Presentation**: Detailed display of ingredients with visual icons, required utensils list, and step-by-step preparation instructions divided into clear phases (mousse, ganache, and final assembly).
- **Affectionate Tribute Section**: Photo gallery organized in custom tables and an emotional message dedicated to mothers, styled using clean container cards.
