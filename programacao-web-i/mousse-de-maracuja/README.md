# 🍋 Mother's Day: Passion Fruit Mousse & Chocolate Ganache

A special thematic web project developed for a Mother's Day assignment in Web Programming I at ETEC. The page combines a favorite family dessert recipe with an emotional photo tribute and personal message dedicated to mothers.
