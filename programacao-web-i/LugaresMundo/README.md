# 🌍 Fantastic Places

Web page developed as part of the Web Programming I coursework at ETEC, cataloging remarkable tourist destinations around the world with descriptions, historical context, and personal significance.

## 🚀 Technologies Used

- **HTML5:** Semantic structuring, internal anchor links for quick page navigation, and text formatting.
- **CSS3:** Custom styling and visual presentation organized via external stylesheets (`_css/style.css`).

## ✨ Features

- **Quick Navigation Menu:** Direct anchor links allowing users to jump instantly to any destination profile (from New York and Rio de Janeiro to Tokyo and Big Ben) or return to the top.
- **Detailed Profiles:** Includes rich descriptions, high-resolution imagery (`_img/`), and personal/historical significance for each location.
